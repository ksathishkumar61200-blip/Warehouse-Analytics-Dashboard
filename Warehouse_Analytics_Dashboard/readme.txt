# 📦 Warehouse Analytics Dashboard

An end-to-end Power BI dashboard designed to analyze warehouse performance, inventory levels, demand patterns, operational efficiency, and business risks. This dashboard transforms raw warehouse data into actionable insights that support better inventory planning and decision-making.

---

## 🎯 Project Objectives

- Monitor inventory performance across different product categories.
- Analyze warehouse costs and operational efficiency.
- Identify products that require immediate reordering.
- Track stockouts and overstock situations.
- Compare actual demand with forecasted demand.
- Evaluate warehouse KPIs and fulfillment performance.
- Generate business recommendations based on inventory health.

---

## 🛠️ Tools and Technologies

- Power BI
- Power Query
- DAX
- CSV Dataset

---

## 📊 Key Performance Indicators (KPIs)

| KPI | Description |
| --- | --- |
| Total Products | Total number of products in the warehouse |
| Total Stock | Total inventory available |
| Total Inventory Value | Total value of all products in the warehouse |
| Average KPI Score | Overall warehouse performance score |
| Average Coverage Days | Average inventory coverage period |
| Average Fulfillment Rate | Order fulfillment efficiency |
| Total Stockouts | Total number of stockout incidents |
| Average Lead Time | Average supplier lead time |
| Total Holding Cost | Total inventory holding cost |
| Reorder Items | Products that require replenishment |
